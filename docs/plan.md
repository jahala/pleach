# pleach — build plan

Phases are dependency-ordered; work within a phase parallelizes across modules (one writer per file).
Every ledger item (`docs/ledger.md` §1) lands as a RED test before its fix. Definition of done for the
whole build: **the proof run** — one honest-partial, multi-step tend feature executed end-to-end (claude
builds, codex audits, tend's gate decides), surviving the A1/A2 traps it was chosen to re-trip.

## P0 — bootstrap & contract  `[repo: pleach]`
- Skeleton: `package.json` (private), strict tsconfig, biome, CI (typecheck+lint+test, ubuntu, tmux+git),
  `.gitignore`, test dirs.
- `src/core/plan.ts` — schema v1.1 + drift test against `docs/contract/plan-schema.md`.
- `src/core/errors.ts` — typed error set.
- `src/core/validate.ts` — `validatePlan`: duplicate ids, unknown `needs`, cycles (toposort), audit
  provider ≠ worker provider. *(ledger M1, D3)*
- `src/core/classify.ts` — the error-taxonomy ladder as a pure function. *(D1 rows, C4 row)*

## P1 — substrate seams  `[repo: pleach]`
- `src/seams/exec.ts` — arg-array spawn, `timeoutMs`, cwd, captured output; no shell strings. *(SEC1, S2)*
- `src/seams/lock.ts` — O_EXCL pid lockfile per (repo, source); stale-lock takeover. *(B4/S5)*
- `src/seams/journal.ts` — append-only JSONL run journal.
- `src/seams/isolate.ts` — the git seam, REAL-git tests in tmp repos:
  detached worktree at `baseRefs[0]` + sequential merges; catastrophic-vs-conflict distinction;
  `setup` hook execution; **marker scan** (`git diff --check` equivalent) *(C1)*; **scoped staging** from
  `filesTouched` *(S1)*; `commitBranch` → returns SHA *(B2 ordering)*; dispose. Required tests: fan-out
  (two detached worktrees off one ref), join-with-conflict (markers kept), junk-not-staged, marker-gate
  trips, missing-baseRef → typed catastrophic error, setup-runs-before-gates.

## P2 — worker seam  `[repos: provo (R1 PR) → pleach]`
- **R1 in rctrl (PR to provo, ledger-cited):** `wait --json` (+ `--since <mtime>`), `send --json`
  emitting `sinceMtime`, MCP `sinceMtime` wiring, `allowedTools` work-or-error per provider, exit-code
  split input/idle. Each item RED-first in rctrl's own suite.
- `src/seams/rctrl.ts` — `spawnWorker → Worker{send, wait, kill}`; `WorkerResult` assembled from
  `wait --json` + `read` (untruncated) + `actions` (files arrays) + `diff`; maps `input|idle` reasons
  through *(D2)*. Integration tests: real `rctrl` binary + vendored fake worker binaries
  (`test/fixtures/fake-worker.sh`, the rctrl fixture pattern). No mocks.

## P3 — ledger seam  `[repos: missoula (T1, tend agent) ∥ pleach]`
- `src/seams/tend.ts` — `readClosed`/`emitVerdict` over the transport T1 exposes (package export or
  `tend bridge` CLI verb — both acceptable; adapter hides the choice). All calls serialized through one
  in-process queue (single-ingester invariant).
- Until T1 merges: integration tests run against the missoula checkout's real source (`file:` dep or
  `bun` running its TS — real code, not a mock); swap to the released transport when T1 lands.

## P4 — the loop  `[repo: pleach]`
- `src/loop/deps.ts` — seam interfaces (`Deps`), `RunSummary`.
- `src/loop/run-work.ts` — `{prompt}` / `{test, phases}` (RED/GREEN exec gates) / `{command}`.
- `src/loop/run-node.ts` — per-node ladder: isolate → setup → work → marker gate → scoped stage → smoke →
  audit (parse-only, untruncated, `AuditParseError` → re-audit-only) → verdict. Retry ladder per the
  classify table **with evidence-carrying re-prompts** *(A3)*; dead → re-isolate; retryable → reuse.
- `src/loop/run-plan.ts` — scheduler (ready/inflight/race; semaphore), **close paths**: audit nodes →
  tend decides; non-audit nodes → conductor closes on done+gates *(A1)*; **commit-before-emit** *(B2)*;
  baseRef chain `node/<id>` → SHA → typed error *(B1)*; startup reconciliation; lockfile; journal;
  defensive copies *(M3)*.
- Loop tests with in-memory seams: §6 originals (diamond wave order, semaphore, fan-out, join, commit-
  on-verified, dead-retry-re-isolates, runNode sequence, phase gates, failure/retry, ingester derivation)
  + ledger tests (each tagged `// ledger: <id>`).

## P5 — face  `[repo: pleach]`
- `src/faces/cli.ts` — `pleach run <plan.json> [--max-concurrency N] [--land <branch>] [--journal <path>]`,
  `pleach validate <plan.json>`; exit codes (0 all-closed; 1 failures; 2 usage/invalid plan; 3 lock held);
  stdout = the `RunSummary` JSON, stderr = narration. `--land` default OFF (human merges).
- E2E: `pleach run` as a process — real git, real rctrl + fake workers, real tend transport, a 3-node
  plan with one engineered failure+retry.

## P6 — integration & proof  `[repos: all three]`
- `examples/proof/` — guinea-pig project + tend garden: one honest-partial feature with ≥3 steps and a
  cross-feature dep, checks with negctrl. Plan generated by tend's T1 generator (fallback: hand-written
  v1.1 plan, same contract).
- Proof run (`PLEACH_PROOF=1`): claude builds / codex audits / tend gates. **The run names the next
  defect; fix it RED-first.** Record the run report in `docs/research/proof-run.md`.
- Mid-build audit checkpoint (after P4) and final PR-grade review of the whole repo (lead, inline):
  re-read every diff hostile; check bloat, slop, doctrine drift, dead code.

## Cross-repo dependency notes
- P2 blocks on the R1 PR only for `--json`/`--since`; adapter skeleton + fixtures can start against
  shipped rctrl.
- P3's live transport blocks on the tend agent's T1; the missoula-source fallback unblocks pleach
  immediately.
- The proof's generated-plan path blocks on T1 generator changes; the hand-written-plan path doesn't.
